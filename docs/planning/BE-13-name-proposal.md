# BE-13 name

> Status and dates for this document are in `NOTES.md` and `CHANGELOG.md`. The paragraphs below are the proposal as written, before the rename it asked for; the catalog name is the record in `data/bridge-catalog.json`.

The catalog name this proposal was written against is `Information-Geometry Equation (Jacobson 1995 thermodynamic derivation)`.

The equation the entry encodes is the scalar trace `R = 4Λ − (8πG/c⁴) T`. The stored `formalRef` is `PhysJS.Einstein.trace_eq`. Its covers line begins `reduction:` and says that contracting `G_μν + Λ g_μν = κ T_μν` in four dimensions gives `R = 4Λ − κ T`, and that this is not Jacobson's thermodynamic derivation.

The name claims the derivation the covers line excludes. A reader who trusts the name and a reader who trusts the covers line disagree about what the reference certifies.

This note does not rename the entry. A catalog-name change needs the owner's approval, the same care as the bridge 38 rename. The id stays 13. The module file stays. The Jacobson interpretation already lives in the entry's context and notes, where it is framing rather than the certified statement. That prose can stay.

Proposed name, if approved: `Einstein trace reduction`.

An alternative that keeps the framing visible in the name, without claiming the derivation: `Trace of the Einstein equation`. The shorter name is the one this note recommends, because it names the reduction the reference certifies and does not put Jacobson in the name the covers line declines.
