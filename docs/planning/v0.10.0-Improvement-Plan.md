### T2 — Part-IX Phase C: stress tests (≥2, PRE-REGISTERED here)
Compositions that MUST fail diagnosably:
- **ST-1 (junction/dimension mismatch):** `composeEdges(be12Edge,
  be16Edge)` — thermal de Broglie outputs a LENGTH named
  `thermal-de-broglie-wavelength`; Landauer wants `temperature` [Θ]. No
  name match, no registered identification → `CompositionJunctionError`
  naming both quantity sets. Then force it with an ad-hoc
  identification `{from: 'thermal-de-broglie-wavelength', to:
  'temperature'}` → must throw `CompositionDimensionError` citing
  [length] vs [temperature] — the dimension functor refusing a
  physics-nonsense junction even when a human asserts it.
- **ST-2 (domain incompatibility through the pipe):** compose the
  Schwarzschild-radius law into `be51Edge` via an identification
  `schwarzschild-radius → impact-parameter` (physically: a photon
  grazing AT r_s). The junction type-checks ([length]=[length]) but
  be51's weak-field domain `b ≥ 10·r_s` is violated by construction →
  `DomainViolationError` at evaluation. Acceptance: the composed edge
  EXISTS (compose succeeds — the failure is correctly attributed to
  domain, not type).
Part-IX §6 stress-test bar (≥2 surviving stress tests = failures that
the framework names correctly) is met when both pass; whether it is met is
recorded in `NOTES.md`, not here.
