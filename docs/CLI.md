# `upt` command reference

Generated from the command registry by `scripts/cli-reference.ts`. Do not edit this file.
`bun scripts/cli-reference.ts` rewrites it. `bun scripts/cli-reference.ts --check` fails when it is stale.

A bare `e` in a formula is the elementary charge. `E` is energy. Euler's number is `exp(x)`, for example `exp(1)`. The name `euler` is refused.

## Global options

Accepted before the command name. `--json` may also follow the command name on any command that lists it below.

| Flag | Value | Default | Description |
|---|---|---|---|
| `--help` | no |  | Show this command list, or `upt help <command>` for one command. `-h` is the same. `upt <command> --help` prints that command. |
| `--version` | no |  | Print the package version as one semver line and exit. `-v` and `upt version` are the same. Neither takes --json. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |
| `--record=VALUE` | `=` value |  | Run the following command unchanged and append one JSONL entry to FILE: arguments, stdout, stderr, exit code, versions, and hashes. A failed run is recorded too. |
| `--replay=VALUE` | `=` value |  | Re-run every entry of FILE and report reproduced, differs, or not replayable. Takes no command. `--json` after it selects the JSON report. Exit 0 when every entry is reproduced and unchanged, 3 when any differs, 1 otherwise. |
| `--show-record=VALUE` | `=` value |  | Print FILE as a transcript and run nothing. Takes no command. `--json` after it selects the JSON report. |

`upt <command> --help` prints that command and exits 0. An unknown flag exits 2 and names the flag. `upt version` prints one semver line and takes no arguments.

## Evaluate and check

### `audit`

Derive every bridge equation by dimensions and sort derived, coefficient unset, decoy, not a monomial, and open.

```
upt audit [--source=catalog|canonical|both]
```

| Flag | Value | Default | Description |
|---|---|---|---|

| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |

```

### `derive`

Derive the dimensional form of your own equation and, with --formula, the prefactor. Aliases: `dim`.

```
upt derive <target:dim> <var:dim> ... [--formula "<expr>"] [--debug]
```

| Flag | Value | Default | Description |
|---|---|---|---|
| `--formula VALUE` | next token |  | Check EXPR against the declared dimensions and recover the dimensionless prefactor. |
| `--debug` | no |  | Print the formula parser name and version on stderr. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |

```
upt derive period:time length:length gravity:acceleration --formula "2*pi*sqrt(length/gravity)"
```

### `eval`

Evaluate a scalar formula. A bare e is the elementary charge; Euler's number is exp(x). Aliases: `calc`.

```
upt eval "<formula>" name=value ...
```

| Flag | Value | Default | Description |
|---|---|---|---|
| `--debug` | no |  | Print the formula parser name and version on stderr. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |
| `--show-parser` | no |  | Print mathts. With no formula, that is the whole output and the exit code is 0. |
| `--natural` | no |  | Set ħ = c = 1 (and h = 2π) when reading values. |
| `--geometrized` | no |  | Set ħ = c = G = 1 when reading values. |

```
upt eval "2*pi*sqrt(1/9.81)"
```

### `evaluate`

Evaluate a closed-form bridge or an applied case, with units on every input.

```

| Flag | Value | Default | Description |
|---|---|---|---|
| `--sigma=VALUE (repeatable) (or --sigma VALUE)` | `=` or next token, repeatable |  | One input uncertainty as key=u, in the input's unit. A temperature uncertainty in degC or degF is a difference. |
| `--corr=VALUE (repeatable) (or --corr VALUE)` | `=` or next token, repeatable |  | A pairwise correlation as a,b=rho, used with --sigma. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |

```
upt evaluate be-63 mu_e=2
```

### `map`

Show how equations link, or where your own equation lands on that graph. Aliases: `linkage`.

```
upt map [--source=catalog|canonical|both] [--format=text|mermaid|dot|svg]
```

| Flag | Value | Default | Description |
|---|---|---|---|
| `--source=VALUE` | `=` value | both | Which graph to draw: catalog, canonical, or both. This command defaults to both. |
| `--format=VALUE` | `=` value | text | Output form: text, mermaid, dot, or svg. svg needs the optional @viz-js/viz peer. |
| `--out=VALUE` | `=` value |  | Write the report to PATH instead of stdout. |
| `--max-orders=VALUE` | `=` value | 3 | Magnitude-clash threshold for the --proposed overlay. |
| `--anchor=VALUE (repeatable)` | `=` value, repeatable | mass=M_sun | Override a numeric anchor as k=v for the --proposed overlay. |
| `--proposed` | no |  | Overlay unadjudicated identity-consequence relations. |
| `--relation=VALUE` | `=` value |  | Keep atlas edges whose recorded relation is TYPE. |
| `--evidence=VALUE` | `=` value |  | Keep atlas edges whose derived evidence set contains TAG. |
| `--around=VALUE (or --around VALUE)` | `=` or next token |  | Keep edges within --depth shared-quantity hops of QUANTITY. |
| `--depth=VALUE` | `=` value | 1 | Hop count for --around. |
| `--route=VALUE (or --route VALUE)` | `=` or next token |  | Map the atlas route FROM,TO instead of the equation graph. |
| `--all-routes` | no |  | With --route, list every simple route, shortest first. |
| `--max-routes=VALUE` | `=` value | 20 | Cap on --all-routes. The maximum accepted is 1000. |
| `--family=VALUE (or --family VALUE)` | `=` or next token |  | Map one atlas family by name. |
| `--observable=VALUE (or --observable VALUE)` | `=` or next token |  | Map bridges whose recorded text names this observable. |
| `--stored` | no |  | Derive evidence from https://github.com/danielsimonjr/Universal-Physics-Tensor/blob/master/data/atlas/witness-results.json. That file is not in the published package; the command then names --run. |
| `--run` | no |  | Run the shown bridges' in-process witnesses now. Exit 3 if one is refuted. |
| `--equation=VALUE (or --equation VALUE)` | `=` or next token |  | Inject TARGET = EXPR as a user node and report where it lands. |
| `--equation-only` | no |  | Print only the equation verdict. Errors when --equation is missing. |
| `--verbose` | no |  | With --equation, also print the linkage map. |
| `--bind-short` | no |  | Bind a one-letter catalog name in --equation. Without it, those names are reported and not bound. |
| `--natural` | no |  | Set ħ = c = 1 when a dimension difference is a power of those constants. |
| `--geometrized` | no |  | With the natural-unit rules, also set G = 1. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |

```
upt map --equation "period = 2*pi*sqrt(length/gravity)"
```

### `path`

Show the bridge chain between two models and whether a bound is claimed there.

```
upt path <from> <to> [--at group=value ...] [--tolerance=[observable:]EPS]
```

| Flag | Value | Default | Description |
|---|---|---|---|
| `--at=VALUE (repeatable) (or --at VALUE)` | `=` or next token, repeatable |  | State one regime coordinate as group=value. A value may be an expression such as pi/2. |
| `--sweep=VALUE (or --sweep VALUE)` | `=` or next token |  | Sample one coordinate as name=lo:hi:n or name=lo:hi:n:log, with n from 2 to 200. |
| `--compare=VALUE (or --compare VALUE)` | `=` or next token |  | Sweep a second route from the same source to this model id and mark NEITHER where no limit applies. |
| `--csv` | no |  | Write sweep rows as CSV. |
| `--tolerance=VALUE` | `=` value |  | Judge adequacy against EPS in the bound's norm, or name:EPS through a declared translation. Exit 3 when inadequate. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |

```
upt path model-pendulum model-spring --at theta0=0.2 T0=1 t=10
```

### `probe`

Search expressions and residuals. This is not `upt discover`.

```
upt probe <scan|show|run|candidates|falsify|rank|design|reproduce|study>
```

| Subcommand | What it does |
|---|---|
| `scan` | List typed frontier gaps. The default listing is the searchable ones. |
| `show` | Print one gap by id. |
| `run` | Run a bounded search from a problem file. |
| `candidates` | Run the search and list stored statuses. |
| `falsify` | Run the search and print the falsification batteries. |
| `rank` | Run the search and print the Pareto front. |
| `design` | Suggest a discriminating experiment from two hypotheses and bounds. |
| `reproduce` | Re-run a problem file under the same stop contract. |
| `study` | Fit exploratory rows only, then test on withheld holdout and replication rows. |

| Flag | Value | Default | Description |
|---|---|---|---|
| `--source=VALUE` | `=` value | catalog | Which graph a subverb reads: catalog, canonical, or both. |
| `--json` | no |  | Write a JSON envelope to stdout instead of the text report. |
| `--problem=VALUE` | `=` value |  | Problem JSON file for run, candidates, falsify, rank, and reproduce. |
| `--budget-ms=VALUE` | `=` value | 5000 | Wall-clock cap in milliseconds. |
| `--holdout-tol=VALUE` | `=` value | 0.15 | Relative holdout RMSE cap. |
| `--worker=VALUE` | `=` value |  | Optional NDJSON worker, spawned as node PATH. The path must be a .js, .mjs, or .cjs file. |
| `--bounds=VALUE` | `=` value |  | Bounds for design, as the design subverb reads them. |
| `--h1=VALUE` | `=` value |  | First hypothesis for design. |
| `--h2=VALUE` | `=` value |  | Second hypothesis for design. |
| `--searchable-only` | no |  | scan: list only Product-B-searchable gaps. This is the default. |
| `--all` | no |  | scan: include Product A wrappers, which are not searchable here. |
| `--data=VALUE` | `=` value |  | Study file (JSON, or CSV when the name ends in .csv) for study. |
| `--replication=VALUE` | `=` value |  | study: replication rows from a separate JSON or CSV file. |
| `--alpha=VALUE` | `=` value | the file's alpha, else 0.001 | study: χ² test level. |

```
upt probe scan
```
