# UPT — loader

This file only loads the repository's records. It states nothing itself: each fact lives in
exactly one of the files below, and `AGENTS.md` says which kind goes where.

- `AGENTS.md` — the law: what the repo is, the rules, the boundaries.
- `WORKFLOWS.md` — procedure: what to run, in order.
- `TOOLS.md` — the commands, and how each instrument misleads.
- `MEMORY.md` — stateless facts: stack, source map, grammar, invariants.
- `NOTES.md` — dated state: criteria, results, open defects, measured counts.

Open work and the authorization gate are in `ACTIVE.md`, history in `CHANGELOG.md` (what landed)
and `todo.md` (the closed task ledger), and the vision in `README.md`.
